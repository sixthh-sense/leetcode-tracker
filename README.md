# leetcode-tracker

Java 17로 푼 LeetCode 풀이 기록입니다.
각 풀이 파일 맨 위 주석에 핵심 관찰, 복잡도, 실수, 다시 풀기 결과를 남깁니다.

## 구조

```
src/main/java/leetcode/<유형>/p<문제번호>/Solution.java
src/test/java/leetcode/<유형>/p<문제번호>/SolutionTest.java
```
